# SHAHEEN AI 🦅

![SHAHEEN AI](./branding/shaheen-ai.png)

**SHAHEEN AI** is a modern self-hosted AI platform built on the Open WebUI technology foundation and redesigned under the SHAHEEN AI identity.

## Project Overview

SHAHEEN AI is designed to provide a self-hosted AI platform for running, managing, and integrating AI models and tools while keeping the infrastructure under developer control.

The project can be deployed on Linux cloud infrastructure with persistent application data and configurable services.

## Core Capabilities

- AI model integration
- AI agents and workflows
- Knowledge bases and RAG
- Web search and web access
- Tools and integrations
- Advanced AI conversations
- File and document processing
- Image generation integrations
- Voice capabilities
- Responsive web interface
- Progressive Web App support
- Authentication and user management
- Multi-user support
- Persistent data storage
- Self-hosted deployment
- OpenAI-compatible APIs
- Docker deployment
- Multilingual interface
